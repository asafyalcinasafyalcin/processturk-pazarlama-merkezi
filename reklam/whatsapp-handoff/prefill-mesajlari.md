# WhatsApp Açılış (Pre-fill) Mesajları

Click-to-WhatsApp reklamında "Send message" sonrası kullanıcının sohbetine **ön-dolu** gelen metin.

`[REKLAM: ...]` etiketi chatbot'a ürün/kampanya bağlamını taşır.

---

## C1 — Hazır Makineler

**Granül Dolum Makinesi**
```
TR-A: Merhaba, Granül Dolum Makinesi için teklif almak istiyorum. [REKLAM: C1-granul]
TR-B: Merhaba, paketleme makinesi fiyatı hakkında bilgi almak istiyorum. [REKLAM: C1-granul]
EN:   Hello, I'd like a quote for the granule filling machine. [REKLAM: C1-granul]
AR:   مرحبًا، أريد عرض سعر لماكينة تعبئة الحبيبات. [REKLAM: C1-granul]
FR:   Bonjour, je voudrais un devis pour la machine de remplissage de granules. [REKLAM: C1-granul]
```

**Sıvı Dolum Kafası**
```
TR:   Merhaba, Sıvı Dolum Kafası hakkında bilgi ve fiyat istiyorum. [REKLAM: C1-sivi-kafa]
EN:   Hello, I'd like information and pricing for the liquid filling head. [REKLAM: C1-sivi-kafa]
AR:   مرحبًا، أريد معلومات وسعر رأس تعبئة السوائل. [REKLAM: C1-sivi-kafa]
FR:   Bonjour, je voudrais des informations sur la tête de remplissage liquide. [REKLAM: C1-sivi-kafa]
```

**Etiketleme Makinesi**
```
TR-A: Merhaba, etiketleme makinesi için teklif istiyorum. [REKLAM: C1-etiket]
TR-B: Merhaba, otomatik etiket makinesi fiyatları nedir? [REKLAM: C1-etiket]
EN:   Hello, I'd like a quote for a labeling machine. [REKLAM: C1-etiket]
AR:   مرحبًا، أريد عرض سعر لماكينة لصق الملصقات. [REKLAM: C1-etiket]
FR:   Bonjour, je voudrais un devis pour une machine à étiqueter. [REKLAM: C1-etiket]
```
